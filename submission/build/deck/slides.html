03 · The solution

Several mirrors. One truth.

01 · VERIFY

Quorum + cryptography

Ask several mirrors, recompute Hedera's SHA-384 running hash, check it ends at the consensus-node anchor.

02 · EXPLAIN

AI forensic report

Which mirror lied, how, at which sequence numbers, and what to do about it.

03 · PROVE

Audit trail on HCS

Every verdict and its report hash are attested on the Hedera Consensus Service.

Golden ruleThe AI proposes. Deterministic logic and cryptography decide.
Aymane · 1:05–1:45. HashWitness does three things. [→] It verifies: it asks several mirrors, recomputes Hedera's own SHA-384 running-hash chain, and checks that it ends at the hash a consensus node reports. A forged history cannot. [→] It explains: an AI agent writes a forensic report. [→] It proves: every verdict is attested on the Hedera Consensus Service. [→] One golden rule: the AI proposes, cryptography decides. [→ next slide]

07 · Vision

Don't trust the mirror. Verify it.

What's different

  • Cryptographic anchor, not a majority vote
  • Works with today's mirror APIs
  • AI that explains, never decides

Honest limits

  • 2 real mirrors, attacker simulated
  • Anchor from one consensus node
  • Mirror lag can look like replay
